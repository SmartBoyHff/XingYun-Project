一、提交信息格式
text
[分类] 类型: 简短描述

二、分类说明
分类	含义	示例
[模块4]	维护保养	[模块4] feat: 添加胎压表加压功能
[模块5]	智能传感器[模块5] fix: 修复终端指令大小写匹配
[模块6]	整车制造	[模块6] refactor: 优化机械臂关节控制
[通用]	通用框架	[通用] feat: 添加对象池工具类
[资产]	资产导入	[资产] asset: 导入智界S7模型
[配置]	项目配置	[配置] chore: 更新XRIT版本
[文档]	文档更新	[文档] docs: 更新开发指南

三、类型说明
类型	含义
feat	新功能
fix	Bug修复
docs	文档
refactor	重构
chore	杂务/配置
asset	资产

四、操作流程
4.1 日常提交

"git add .
git commit -m "[模块4] feat: 添加胎压表长按加压"
git push origin develop/vr"

4.2 拉取更新

"git checkout develop/vr
git pull origin main"

4.3 合并到主分支
完成后在GitHub创建Pull Request：

标题：[VR] 模块4: 完成胎压检查功能

描述：简要说明完成内容

目标分支：main

五、提交示例

# 新功能
git commit -m "[模块4] feat: 添加胎压表加压功能"

# 修复Bug
git commit -m "[模块5] fix: 修复终端指令匹配问题"

# 导入资产
git commit -m "[资产] asset: 导入传感器模型"

# 更新文档
git commit -m "[文档] docs: 更新VR团队代码规范"
